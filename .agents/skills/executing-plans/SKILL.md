# Executing Plans

## Overview

Execute an approved implementation plan with discipline, verification, and precision.

## Execution Rules

1. **Follow the plan task-by-task**: Never jump ahead or skip verification steps.
2. **Apply TDD for each task**: Write failing tests before implementation code.
3. **Verify at each checkpoint**: Ensure all automated tests and build checks pass before moving to the next task.
4. **Halt on unexpected failures**: If an assumption in the plan fails, stop and re-evaluate rather than hacking around it.
