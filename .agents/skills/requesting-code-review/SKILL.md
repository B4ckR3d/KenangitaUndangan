# Requesting Code Review

## Overview

Structure your pull request or code changes for an effective, two-stage code review.

## Review Stages

1. **Spec Compliance**: Verify that all requirements from the plan/spec are completely fulfilled without scope creep.
2. **Code Quality**: Check for adherence to architectural standards, type safety, error handling, performance, and security best practices.
